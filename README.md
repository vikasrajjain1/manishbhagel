## 🌐 How to Host Online for FREE

### Method 1: Netlify Drop (Easiest - 30 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the whole `manish` folder.
3. Your portfolio is immediately live with a free custom URL (e.g., `manish-baghel.netlify.app`).

### Method 2: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under *Branch*, select `main` and save.
4. Your website will be live at `https://<your-username>.github.io/<repo-name>/`.
